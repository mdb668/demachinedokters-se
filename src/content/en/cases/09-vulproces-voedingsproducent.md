challenge: "The filler did not always start and stop at exactly the right moment. As a result, product landed next to and between the packages. That contaminated packages, conveyor belts and machines. Contaminated packages cannot be sold, and the line regularly had to stop for cleaning. On top of that, there was no certainty that every package was properly sealed.\n\nThe solution became an extra operator checking every package 24 hours a day. It started as a temporary measure after an incident, but quietly became standard practice. An expensive habit that nobody saw as a problem any more."
approach: "Instead of buying a new filler, we improved the existing filling method. We precisely tuned the timing of when the filler starts and stops, so the product ends up where it belongs.\n\nWe also added an air blow-off system. It keeps the filling nozzle clean after every fill, so no more product falls between the packages and the seal stays reliable.\n\nWe first built the solution as a temporary setup to validate in practice that it worked, and to fine-tune the timing and blow-off. Only once the result was proven did we carry out the permanent installation. The photo was taken during that test phase, so the cable ties are there on purpose.\n\nThe modification is built so that it does not get in the way of the original machine supplier and so that our system runs smoothly with the continuous process. We commissioned the system and trained the operators."
