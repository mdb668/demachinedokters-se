When something goes wrong, we solve it so that it stays solved. With a fault analysis we find the real cause. We know both mechanics and control engineering, so we fix the fault and prevent it from coming back.

## Does this sound familiar?

- The same fault returns every week, always in the same place.
- The line has lots of short stops that nobody records any more.
- One experienced operator always gets the machine running again, the others do not.
- A temporary fix has quietly become the normal way of working.

Then the cause has not been found yet.

## How we approach a fault analysis

1. **Collect.** Fault logs, PLC data and above all the stories of the operators and maintenance technicians who stand next to the machine every day.
2. **Measure.** We read out the data the machine already has, or fit extra sensors where needed: vibration, temperature, current draw, timing.
3. **Isolate the cause.** Mechanical, electrical, controls or operation? It often sits at the boundary, and that is exactly where we look.
4. **Solve and validate.** Where possible first built as a temporary set-up to test and fine-tune, then made permanent.
5. **Secure the result.** We set up maintenance so the fault stays away, and we teach your people to recognise the signs themselves.

## What we need for a fault analysis

How an analysis runs depends on the situation. We want to know how the line is running, and we need to see the fault or be able to reproduce it. Or there has been a crash that we need to repair.

## Fault analysis of electric drives, sensors and controls

We also analyse faults in electric drives, sensors and controls (PLC). Faults often sit at the boundary between mechanics, electrics and controls. Because we look at those disciplines together, we find causes that fall between the cracks when a mechanic or a programmer works alone. We work independently of brand.

## Analysis only, with a report

You can also have us do just the analysis, without implementation. You then receive a report with priorities, risks and expected return.
